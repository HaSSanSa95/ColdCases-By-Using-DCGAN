## Abstract

This research explores the application of **Deep Convolutional Generative Adversarial Networks (DCGANs)** to reconstruct and synthesize human facial images for forensic purposes.
The goal is to **support cold case investigations** by providing advanced AI-based image reconstruction techniques that enhance suspect and victim identification when evidence is incomplete or degraded.
